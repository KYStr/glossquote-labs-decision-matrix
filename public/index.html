比較工作區

下載檔案會包含你輸入的文字、權重與分數。只開啟自己選擇的 JSON 比較檔，最多 64 KiB。

準則與權重

權重 0–100，不必合計 100。成本型評的是負擔程度：1 低、5 高。

方案評分

效益：1 低、5 高 · 成本：1 低負擔、5 高負擔
2–8 個方案 · 1–8 項準則

排序與明細

分數呈現你的輸入，不代表客觀最佳答案，也不是機率。

前列方案差異沿用排行前兩個方案，列出同名次的完整群組。正差表示前者在該準則較有利，負差表示後者較有利；成本的原評分仍表示負擔程度。

怎麼比較與核對

  1. 命名方案與準則，設定每項準則的方向及相對重要程度。
  2. 為每個方案填 1–5 分。正權重格子缺分時，整份比較暫不顯示排行。
  3. 查看排序，展開加權明細。改權重或分數時，結果即時更新。
  4. 想保留草稿時，自行下載 JSON 檔；下次選檔開啟並確認取代。

公開公式

效益 u = 評分 − 1；成本 u = 5 − 評分。分子 N = Σ（權重 × u），總權重 W = Σ 權重，百分制分數 = 25 × N ÷ W。權重 0 不計入；總權重 0 不排名。

以整數 N 比較；平手維持原方案順序，名次為 1、1、3。顯示分數至小數點後兩位。這是整理主觀取捨的模型，不替你做決定。

資料處理與限制

沒有帳號、上傳、分析追蹤或自動保存。載入網站資產後，評分與檔案處理在裝置上完成。清空不會刪除已下載檔案。語言切換會開啟另一語頁，請先下載以保留內容。

最多 8 × 8 格，標題 80 字、名稱 40 字；UTF-8 JSON 檔限 65,536 bytes。瀏覽器能力缺失會禁用檔案功能，核心比較仍可使用。

常見問題

權重要加起來等於 100 嗎？

不用。按總權重換算比例；權重 0 的準則不計入。

成本型怎麼給分？

評成本或負擔程度：1 低、5 高；計算時反轉成越低越有利。

有些格沒填會怎樣？

任何大於 0 權重的格子未評分，就暫不顯示所有方案的總分與排行。

第一名一定最適合我嗎？

排名由你設定的準則、權重與評分計算。它幫助整理取捨，不能替代情境判斷。

可以保存再繼續嗎？

可自行下載 JSON 比較檔，之後選檔開啟。本工具不自動儲存或同步。
